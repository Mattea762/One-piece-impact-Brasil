# One Piece — Grand Line

Projeto de fã estático, sem backend.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos mantendo as pastas.
3. Vá em **Settings → Pages**.
4. Em Source, selecione **Deploy from a branch**.
5. Escolha `main` e `/ (root)`.
6. Salve e aguarde a publicação.

O site usa HTML, CSS e JavaScript puro. As artes dos cards usam emojis estilizados para evitar depender de imagens oficiais protegidas.


## Seção de mangá
Foi adicionada uma seção com:
- carrossel com setas e indicadores;
- galeria responsiva;
- visualização ampliada (lightbox);
- estrutura preparada para imagens autorizadas.

As imagens reais das páginas do mangá não foram incluídas no pacote.
